# Casos de análisis del diplomado

Ejercicios académicos del certificado de análisis de datos de Laboratoria e IBM. Las dos adaptaciones de SQL incluyen datos sintéticos y resultados esperados. Las fichas descriptivas conservan el contexto de los demás casos documentados.

| Caso | Evidencia disponible en el repositorio |
| --- | --- |
| [Retención de una startup](retencion-startup/README.md) | Consulta de GoogleSQL autocontenida para calcular actividad y retención por cohorte. |
| [Segmentación de comercio electrónico](segmentacion-ecommerce/README.md) | Consulta de GoogleSQL autocontenida para calcular y puntuar métricas RFM con fecha de corte fija. |
| [Telecomunicaciones](telecom-powerbi/README.md) | Ficha del caso de rotación de clientes y del reporte en Power BI. |
| [Análisis exploratorio de COVID-19](analisis-covid/README.md) | Ficha del análisis temporal y geográfico. |
